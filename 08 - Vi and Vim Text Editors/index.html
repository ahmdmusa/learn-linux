    08 - Vi and Vim Text Editors

    السابق: 07 - How to Install Software in Linux | التالي: 09 - Linux User Accounts

    1. ما هو Vim؟

    Vi / Vim (Vi IMproved)

    محرر نصوص يعمل في الـ Terminal. Vim هو نسخة محسّنة من Vi.
    موجود في كل توزيعات Linux تقريباً — لذلك لازم تعرفه.

    ليه نستخدم Vim وفيه محررات أسهل؟

    • متاح دائماً حتى في السيرفرات البدائية بدون GUI.
    • عبر SSH لا تستطيع فتح VS Code أو Notepad.
    • بعد إتقانه يكون سريع جداً.

    2. المفهوم الأساسي: الـ Modes (الأوضاع)

    أهم شيء في Vim هو فهم الـ Modes!

    Vim لا يعمل كمحرر عادي. له أوضاع مختلفة وكل وضع له وظيفة.

    Vim Modes:

  Normal Mode  ← الوضع الافتراضي        
  (للتنقل والأوامر، لا للكتابة)         
          i أو a أو o                  

  Insert Mode  ← وضع الكتابة            
          Esc                          

  Normal Mode                           
          :                            

  Command Mode ← وضع الأوامر (حفظ/خروج)

    3. فتح وإنشاء ملف

    vim filename.txt      # فتح أو إنشاء ملف
vi filename.txt       # نفس الشيء (vi الأقدم)

    4. Normal Mode (الوضع الافتراضي)

    عند فتح Vim، أنت في Normal Mode. لا تستطيع الكتابة هنا.

    التنقل في Normal Mode:

    h ← يسار  |  l → يمين  |  j ↓ أسفل  |  k ↑ أعلى
    (أو استخدم أسهم الكيبورد)

    الأمر الوظيفة
    gg الذهاب لأول الملف
    G الذهاب لآخر الملف
    5G الذهاب للسطر 5
    0 أول السطر
    $ آخر السطر
    w كلمة للأمام
    b كلمة للخلف

    5. الدخول لـ Insert Mode (وضع الكتابة)

    المفتاح الوظيفة
    i Insert قبل المؤشر
    a Append بعد المؤشر
    o سطر جديد تحت الحالي والدخول للكتابة
    O سطر جديد فوق الحالي
    I الذهاب لأول السطر والكتابة
    A الذهاب لآخر السطر والكتابة

    الخروج من Insert Mode → اضغط Esc

    6. أوامر التعديل في Normal Mode

    الأمر الوظيفة
    dd حذف سطر كامل
    d5d أو 5dd حذف 5 أسطر
    yy نسخ سطر (Yank)
    p لصق (Paste)
    u Undo (تراجع)
    Ctrl + r Redo (إعادة)
    x حذف حرف
    cw تغيير كلمة
    r استبدال حرف واحد

    7. Command Mode (وضع الأوامر)

    للدخول: اضغط : في Normal Mode

    الأمر الوظيفة
    :w حفظ (Write)
    :q خروج (Quit)
    :wq حفظ وخروج
    :q! خروج بدون حفظ (قسري)
    :wq! حفظ وخروج قسري
    :set number إظهار أرقام الأسطر
    :/كلمة البحث عن كلمة
    :s/قديم/جديد/g استبدال في السطر الحالي
    :%s/قديم/جديد/g استبدال في كل الملف

    8. البحث في Vim

    /كلمة     ← بحث للأمام
?كلمة     ← بحث للخلف
n         ← النتيجة التالية
N         ← النتيجة السابقة

    9. ورقة المرجع السريع (Cheat Sheet)

                   VIM CHEAT SHEET                   

  الدخول للكتابة  i a o O I A                   
  الخروج منها    Esc                           

  التنقل         hjkl  gg  G  0  $  w  b       

  حذف            dd  x  dw                      
  نسخ/لصق        yy  p                          
  تراجع          u  Ctrl+r                      

  حفظ وخروج      :wq  :q!  :w  :q              
  بحث            /كلمة  n  N                   
  استبدال        :%s/old/new/g
